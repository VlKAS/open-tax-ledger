# Code of Conduct

OpenTax Ledger follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal appearance,
race, caste, color, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language.
- Respecting different viewpoints and experiences.
- Giving and accepting constructive feedback.
- Focusing on what is best for the community.
- Showing empathy toward other community members.

Examples of unacceptable behavior:

- Harassment, intimidation, or discrimination.
- Trolling, insulting or derogatory comments, and personal attacks.
- Publishing others' private information without explicit permission.
- Sharing real taxpayer, broker, identity, or financial data in project spaces.
- Conduct that would reasonably be considered inappropriate in a professional
  setting.

## Enforcement

Project maintainers are responsible for clarifying and enforcing standards of
acceptable behavior. Maintainers may remove comments, commits, code, issues,
and other contributions that violate this Code of Conduct. Maintainers may also
ban contributors temporarily or permanently for behavior they deem harmful.

## Reporting

Report Code of Conduct concerns privately to the maintainers using the contact
method published in the repository profile or release notes.

If a report includes security-sensitive or personal financial information, use
the process in [SECURITY.md](SECURITY.md) and provide only synthetic examples
when possible.
